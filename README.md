# 📨 Email Newsletter — Веб-приложение для управления email-рассылками

**Email Newsletter** — это веб-приложение на Django, позволяющее пользователям создавать, управлять и отправлять email-рассылки клиентам. Проект идеально подходит для маркетинговых агентств, стартапов или любого бизнеса, которому нужно регулярно взаимодействовать с аудиторией по электронной почте.

---

## 🚀 Основные возможности

- ✅ **Управление подписчиками**: добавление, редактирование, удаление получателей.
- ✅ **Создание писем**: тема и тело письма с поддержкой HTML (опционально).
- ✅ **Планирование рассылок**: настройка времени и периодичности отправки.
- ✅ **Статусы рассылок**: черновик, запущена, завершена, отменена.
- ✅ **Отправка через SMTP**: интеграция с почтовыми сервисами (Yandex, Gmail и др.).
- ✅ **Аутентификация пользователей**: регистрация, вход, восстановление пароля.
- ✅ **Интерфейс администратора**: полный контроль через Django Admin.

---

## 🛠 Стек технологий

| Категория       | Технологии                                                                 |
|----------------|----------------------------------------------------------------------------|
| **Бэкенд**      | Python, Django 6.0+                                                         |
| **Фронтенд**    | HTML5, CSS3, Bootstrap 5, Django Templates                                  |
| **База данных** | PostgreSQL (рекомендуется), SQLite (для разработки)                         |
| **Аутентификация** | Django Auth, встроенные формы входа/регистрации                          |
| **Email**       | SMTP (Yandex, Gmail), `django.core.mail`                                    |
| **Хранение файлов** | `Pillow` — для обработки изображений (например, аватаров)             |
| **Деплой**      | Gunicorn, Nginx, Docker (опционально), PostgreSQL                           |
| **CI/CD**       | GitHub Actions (опционально)                                                |
| **Верстка**     | Адаптивный дизайн с использованием Bootstrap                                |
